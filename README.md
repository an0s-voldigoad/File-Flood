# 🌊 FILEFLOOD

**FileFlood** is a lightweight, interactive Linux CLI utility designed to generate, expand, inspect, hash, benchmark, and test files of custom sizes.

Instead of remembering complicated terminal commands, FileFlood provides an interactive menu that guides you through each operation.
